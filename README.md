# 스트림스(Streams) 중국어 숫자 뽑기 앱

보드게임 **스트림스(Streams)** 를 중국어 숫자 학습과 함께 즐길 수 있도록 제작한 웹 애플리케이션입니다.

## 카드 덱 구성 (총 40장)
- **1 ~ 10** (`一` ~ `十`): 각 **1장** (총 10장)
- **11 ~ 19** (`十一` ~ `十九`): 각 **2장** (총 18장)
- **20 ~ 30** (`二十` ~ `三十`): 각 **1장** (총 11장)
- **★ 별표 카드** (`星 · 百搭`): **1장** (원하는 숫자로 사용할 수 있는 조커 카드)

## 주요 기능
- **중앙 메인 카드 대형 표시**: 교실 화면이나 프로젝터에서도 잘 보이도록 뽑힌 카드를 화면 정중앙에 크게 배치했습니다.
- **한자 및 중국어 발음 병기**: 모든 카드에 중국어 한자(`一`~`三十`, `★ 星`)와 한어병음(`yī`~`sān shí`), 한국어 발음 가이드(`[이]`~`[싼스]`)를 함께 표기했습니다.
- **원어민 중국어 발음 듣기(TTS)**: 카드를 뽑을 때 자동으로 중국어 발음을 읽어주며, 언제든 다시 듣기가 가능합니다.
- **수업용 퀴즈 모드**: 아라비아 숫자 가리기 또는 발음 표기 가리기 모드를 켜서 학생들이 먼저 한자/발음을 읽고 정답을 확인하도록 활용할 수 있습니다.
- **뽑힌 순서 기록 및 40장 카드 현황판**: 현재까지 뽑힌 카드의 순서와 남은 카드(특히 2장씩 들어있는 11~19 카드의 잔여 수량)를 한눈에 확인할 수 있습니다.
